ความสามารถ วิธีใช้
แคช layer ตาม digest coral pull alpine:3.20 — layer ที่เคยดึงแล้วถูกใช้ซ้ำจาก .layer-cache/sha256/
ค้นหาชื่อบริการในเครือข่าย coral run --network app-net --network-alias db ... — resolve ได้ทั้ง db และ db.coral.local
BuildKit heredoc & mount RUN --mount=type=cache,target=/root/.cache/pip ... — รองรับ type=cache, type=secret และ type=tmpfs
Docker Engine API DOCKER_HOST=unix:///run/coral/docker.sock docker ps — ใช้กับ Docker CLI, Testcontainers, Traefik และ Portainer ได้
GPU และอุปกรณ์ coral run --gpus all --device /dev/video0:/dev/video0:ro ... — รองรับ NVIDIA, AMD ROCm และ DRM
Alias และ log driver --network-alias และ --log-driver — รองรับ raw, json-file, syslog และ journald 

services:
  trainer:
    image: nvcr.io/nvidia/cuda:12.4.0-base-ubuntu22.04
    gpus: all
    devices: ["/dev/video0:/dev/video0:ro"]
    log_driver: json-file
    aliases: [trainer-alias]
